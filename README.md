# 🐾 PetFeliz Petshop

Projeto desenvolvido para a disciplina **Fundamentos de Sistemas Web** — Fase 1  
Curso de Análise e Desenvolvimento de Sistemas (ADS) — PUCRS EaD

---

## 📋 Sobre o Projeto

Sistema web estático para um petshop fictício chamado **PetFeliz**, desenvolvido com HTML puro.  
Nesta fase, o foco é a estruturação semântica das páginas, sem uso de CSS ou JavaScript.

---

## 📄 Páginas

| Página | Arquivo | Descrição |
|---|---|---|
| Início / Produtos | `index.html` | Página principal com 3 categorias de produtos |
| Serviços | `servicos.html` | Serviços oferecidos pelo petshop |
| Sobre / Contato | `sobre.html` | Informações institucionais e formulário de contato |

---

## 🛍️ Categorias de Produtos

- **Rações** — Ração Premium para Cães e para Gatos
- **Acessórios** — Coleira Ajustável e Brinquedo Interativo
- **Higiene e Beleza** — Shampoo para Pets e Kit Escova de Dentes

---

## 🔧 Serviços Oferecidos

| Serviço | Valor | Busca a Domicílio |
|---|---|---|
| Banho e Tosa | R$ 80,00 | ✅ Disponível |
| Consulta Veterinária | R$ 150,00 | ❌ Não disponível |
| Hotel para Pets | R$ 120,00/diária | ✅ Disponível |
| Adestramento | R$ 600,00 (8 sessões) | ❌ Não disponível |
